# 하루미 대륙 — 큰 지도 설계 (2026-10-04)

하루미 섬(224x224m, 지역 하나가 50~80m)은 걸으면 테마가 너무 빨리 바뀌었다.
**1024x1024m** 로 넓혀 지역 하나를 200~300m(뛰어서 약 1분)로 잡고, 초원을 한가운데 둔다.

## 다른 게임에서 가져온 것

## 큰 구조

카메라는 늘 북쪽을 본다. 그래서 **남쪽이 낮고 북쪽으로 갈수록 계단처럼 높아지게** 짰다.
절벽은 남쪽(카메라 쪽)을 보고 서서 폭포가 화면에 보이고, 한 층 올라설 때마다 다음 풍경이 열린다.

```
 z=0   ▲▲▲ 서리 산맥 (설산 배경, 지도 밖까지 이어짐)              ← Lv 22~30
       노을 만 │ 서리 고원: 눈꽃 마을 · 얼어붙은 호수 · 온천
       (바다)  │════ 절벽 B (z≈200, +20m, 얼음 폭포) ═══════
       단풍 협곡 │ 고목의 숲 · 세계수 │ 안개 호수 │ 옛 성터       ← Lv 12~22
       (산사·탑) │                                  │
 z≈430 ══ 절벽 A (+15m) ══ 벚꽃 폭포 ══ 큰 폭포 ══ 동쪽 오르막 ═══
       벚꽃 골짜기 │      바람의 초원 · 거울 호수      │ 꽃 들판    ← Lv 1~10
       (하나미 마을·신사) │ 약속의 나무 · 거석 원 · 쉼터 │ (풍차·튤립) │ 등대 곶
 z≈850         │        하루미 마을 (시작, 항구)       │
 z=1024 ~~~~~~~~~~~~~~~~~~~~~ 남쪽 바다 ~~~~~~~~~~~~~~~~~~~~~~~~
```

- **초원이 한가운데**, 남쪽 시작 마을에서 나와 가장 먼저 만나는 넓은 들. 여기서 길이 서(벚꽃)·동(꽃)·북(절벽 위)으로 갈라진다.
- **경계는 섞인다**: 초원 서쪽 끝에 벚나무가 한두 그루씩 보이기 시작해 골짜기에서 숲이 되고, 동쪽 끝은 들꽃이 점점 줄을 맞춰 꽃밭이 된다. 영역을 칼로 자르지 않는다.
- **높이**: 해안 0m → 초원 3~15m 구릉 → 절벽 A 위 20~35m → 절벽 B 위 45~70m → 봉우리 100m+.
- **물길**: 큰 강은 설산에서 안개 호수 → 절벽 A 의 큰 폭포 → 거울 호수 → 하루미 마을 → 바다. 서쪽 강은 단풍 협곡 → 벚꽃 폭포 → 벚꽃 골짜기 → 바다. 강이 길잡이 선이 된다.

## 지역

| 지역 | 대표 수종·색 | 랜드마크 / 볼거리 | 레벨 |
|---|---|---|---|
| 하루미 마을 (남) | 참나무·화단 | 분수 광장, 항구, 휘어진 골목 (줄 맞춘 집 없음) | 안전 |
| 바람의 초원 (중앙) | 참나무·포플러, 연두 | 언덕 위 외딴 큰 나무 '약속의 나무', 거석 원, 갈림길 쉼터, 망루 폐허, 야영지, 거울 호수·섬 정자 | 1~6 |
| 벚꽃 골짜기 (서) | 벚나무, 분홍 | 천년 벚나무, 벚꽃 터널 길, 붉은 다리, 하나미 마을, 언덕 위 신사와 도리이 길, 벚꽃 폭포 | 5~10 |
| 꽃 들판 (동) | 들꽃 띠·라벤더, 노랑·보라 | 언덕 위 풍차 셋, 튤립 줄밭, 해바라기밭, 꽃 마을·온실·벌통 | 5~10 |
| 등대 곶 (동쪽 해안) | 소나무, 바다색 | 등대, 바다 절벽 전망 벤치 | 8~12 |
| 단풍 협곡 (북서, 절벽 위) | 단풍·은행, 주황·노랑 | 산사와 탑, 은행나무 길, 협곡 다리, **노을 절벽**(북북서 바다로 해가 진다) | 12~18 |
| 고목의 숲 (북, 절벽 위) | 거목·이끼, 짙은 초록 | 숲 위로 솟은 세계수 (초원에서도 보인다), 이끼 낀 석조 아치 | 14~20 |
| 안개 호수 (북동, 절벽 위) | 버드나무·수련 | 밤 반딧불이, 호숫가 석등, 옛 성터 | 16~22 |
| 서리 고원 (최북단) | 눈 덮인 전나무, 흰색·청색 | 눈꽃 마을의 따뜻한 창불, 얼어붙은 호수, 얼음 폭포, 온천 김, 밤 오로라 | 22~30 |

## 길

- **큰길 셋**: 하루미 마을 → 초원 쉼터(갈림길) → ① 북쪽: 거울 호수 동쪽 → 절벽 A 지그재그 오르막 → 안개 호수 → 절벽 B 고개 → 눈꽃 마을
  ② 서쪽: 벚꽃 터널 → 하나미 마을 → 신사 → 절벽 A 돌계단 → 단풍 협곡 산사 → 노을 절벽 ③ 동쪽: 꽃 마을 → 풍차 언덕 → 등대 곶 → 동쪽 오르막 → 안개 호수.
- **북쪽 고리길**: 단풍 협곡 ↔ 고목의 숲 ↔ 안개 호수 (절벽 A 위), 서쪽 산길 ↔ 서리 고원 ↔ 눈꽃 마을 (절벽 B 위). 막다른 길이 없다.
- 길은 언덕을 돌아가며 휜다. 곧은 길은 마을 안과 꽃밭 둑뿐.
- 큰길에서 오솔길이 갈라져 볼거리로 간다 (야영지, 거석 원, 전망 벤치 …).

## 반복을 없애는 법

- 나무 한 종에 그림 3~4장 + 좌우 뒤집기 (지금은 한 장).
- 고르게 뿌리지 않는다: 숲(덩어리)·빈터·외딴 나무가 섞이도록 저주파 잡음으로 '숲이 될 곳'을 먼저 정하고, 그 안에서 간격을 지키며 심는다. 나무 밑에 고사리·버섯, 숲 가장자리에 덤불.
- 마을은 휘어진 길을 따라 집을 띄엄띄엄 앉히고, 집마다 마당 살림이 다르다.
- 지면 무늬는 좌표 해시라 원래 반복이 없다. 새 지면: 눈·얼음·이끼·바위땅·돌계단·은행잎·밀밭·튤립 줄밭·라벤더 줄밭.

## '종이 같다' — 원인과 해결

스프라이트는 카메라를 보는 판이라 빛이 판 전체에 똑같이 닿고, 판 밑이 땅에 칼같이 잘려 붙어 있고, 멀고 가까운 것이 똑같이 또렷하다.

1. **판에 부피를 준다** — 그림의 외곽선에서 거리를 재어 둥근 법선 지도를 만들고(`tools/normals.py`) 해 방향으로 툰 음영을 준다. 해를 등진 쪽 가장자리에는 테두리 빛(림 라이트). 노을 무렵 역광에 실루엣이 금빛으로 빛난다.
2. **땅에 붙인다** — 판 밑에 접지 그늘(부드러운 타원), 그림 아래쪽을 살짝 어둡게.
3. **그림 모양 그림자** — 공·원기둥 그림자 대신 그림 자체를 해 쪽으로 돌려 세운 그림자 판.
4. **깊이** — 거리 안개(대기 원근): 멀수록 하늘색으로 바래고 대비가 준다. 먼 산은 겹겹이 옅어진다.
5. **절벽** — 층층이 단을 짓고 위 가장자리에 풀 처마, 밑에 바위.
6. **움직임** — 지역마다 날리는 것 (꽃잎·낙엽·눈·반딧불이).

## 해 지는 모습

카메라는 북쪽만 보는데 해는 서북서(290°)로 져서 화면 밖이었다. 해의 길을 바꿔 **북북서(340°) 바다 위로 지게** 한다 (판타지 세계).
V 전망은 고개를 거의 수평까지 들어 수평선과 해가 화면에 들어온다. 노을 절벽·등대 곶에서 바다로 해가 지는 것이 보인다.

## 구현 (2026-10-04)

| 무엇 | 어디 |
|---|---|
| 지도 생성 (numpy, 약 2분) | `tools/mapgen/mapgen.py` + `noise.py`. 절벽선·해안선은 `wiggle` 로 크게 흔들고 폭포·호수·곶 자리는 `pinned` 로 붙든다 |
| 절벽 3단 바위턱 | `tier_step` — 턱 위는 풀, 턱 사이는 바위. 길이 지나는 x 띠(`RAMPS_A/B`)만 긴 오르막 |
| 강·폭포 | 강 수면은 지형을 따라 내려가기만 한다(누적 최소). 8m 안에 4m 넘게 떨어지면 폭포 → `meta.waterfalls` |
| 생물군 섞기 | `biome_weights` 의 부드러운 무게 + 덩어리 잡음으로 경계를 섞는다. 소품은 무게에 비례해 뿌려 경계에서 두 숲이 섞인다 |
| 숲 덩어리 | `FLORA` 의 모양: grove(숲)·lone(외딴 나무)·edge(가장자리 덤불)·under(나무 밑)·meadow(꽃 얼룩)·water(물가) |
| 마을 | 길을 따라 집을 띄엄띄엄(남북 길은 한쪽만, 가끔 양쪽), 집마다 마당 살림·꽃밭·울타리·정원수가 다르다 (`YARD`) |
| 1km 그리기 | 지형 두 겹(`TerrainBuilder`), 물 64m 덩어리, 소품 128m 덩어리 × 종류 아틀라스(`PropBuilder`), 풀은 카메라 둘레만(`GrassField`) |
| 종이 같음 | 법선 지도(`tools/normals.py`) + 툰 음영·역광 테두리(`sprite.gdshader`), 그림 밑동 어둡게(contact_ao), 땅 그늘 지도(`PropBuilder.BakeAo`), 절벽 지층·풀 처마·밑동 그늘(`terrain.gdshader`), 거리 안개 |
| 해넘이 | 해의 길(`DayNight.SunPath`): 북북동(14°)에서 떠 북북서(348°)로 진다. 해 원반은 지평선 가까울수록 크고 붉게, 빛 내림. 노을 절벽(100, 372)에서 바다로 |
| V 전망 | `CameraRig`: 누르고 있으면 피치 7°·거리 34m, 이동 키로 70m 까지 둘러보기(주인공은 멈춤). 서 있는 판은 피치에 맞춰 덜 늘린다(`upright_fix`) |
| 먼 산·오로라·날씨 | `BackdropBuilder`(북쪽 끝 너머 설산, 북서는 바다로 비움), 하늘 셰이더 오로라(서리 고원에서 짙게), `Weather`(꽃잎·낙엽·눈) |

### 성능 (i5-8250U + UHD 620, 640x360)
- 보통 시점 5~9ms, V 전망 9~14ms, 22ms 넘는 튐 없음. 시작 약 6초 (소품 아틀라스·충돌).
- V 전망에서 그리기 호출이 300~500개 — 더 무거워지면 먼 나무를 덩어리별 임포스터로 바꾼다.

### 남은 것
- 세계수가 256px(8m)라 다른 나무의 1.6배뿐 — 더 크게 하려면 위아래 두 장으로 쌓는다.
- 산 속 폭포(서리 고원 강)는 비탈을 따라 이어 붙여 길다 — 전망에서 어색하면 절벽 폭포만 남긴다.
- 여신상은 지금은 장식. 빠른 이동·부활 지점은 다음 기능에서.
