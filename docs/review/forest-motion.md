## 숲과 사냥터

월드 범위를 320×256에서 400×288로 확장하고 기존 숲과 겹치는 두 개의 유기적 외곽을 추가했다. 기존 마을과 사냥터 좌표는 유지했다. 새 지역으로 연결되는 굽은 길 2개와 전용 사냥 거점 6개를 추가했다.

| 지역 | 배치 | 재생성 |
|---|---|---|
| 슬라임 갈대 공터 | 슬라임 5마리 | 18초 |
| 슬라임 이슬 분지 | 슬라임 6마리 | 20초 |
| 슬라임 고목 군락 | 슬라임 5마리 | 18초 |
| 고블린 마을 경계초소 | 고블린 4마리 | 28초 |
| 고블린 마을 주거지 | 고블린 5마리 | 30초 |
| 고블린 마을 작업장 | 고블린 4마리 | 26초 |

`Continuous` 거점은 기존 `MonsterSpawner.AddFixedSlot`을 사용해 죽은 개체만 다시 생성한다. 보급품 획득이나 지역 이탈이 재생성 조건에 포함되지 않는다. 기존 거점의 보급품과 재등장 규칙은 유지했다. 고블린은 적이 가까이 없으면 지정한 짧은 작업·경계 동선을 오가며 멈춰 쉬고, 접근하면 기존 전투 AI로 전환한다.

주거지·망루·우물·작업 수레·통나무·장작·텃밭·저장품을 구분해 배치했다. 숲의 나무 밀도와 종류는 군락별로 달라지고, 습지에는 새 PixelLab 버드나무·참나무·타원형 연못 3곳, 능선에는 침엽수, 길 사이에는 석재 유적 공터를 배치했다. 새 버드나무 원본: `819528bd-44e1-4262-93a0-6dddee4389cb`, 파일 `art/objects32/tree_willow.png`.

## 강변과 검증

3D 물가가 사각 타일과 사각 충돌체를 그대로 사용하던 구조를 곡선 수면·둑·동일 윤곽의 충돌체로 바꿨다. 물가 지형만 1/4타일 간격으로 나누고 `HeightAt`도 같은 삼각형을 따라 계산한다. 다리 통행과 건물·몬스터의 알파 윤곽 충돌은 유지한다.

검사 중 통나무 더미의 길 침범을 찾아 배치를 수정했다. 실제 렌더링에서는 강 아래 바닥에 잘못된 타일을 연결해 생긴 검은 띠를 발견해 정상 잔디 타일로 수정했다. 보급품이 없는 새 거점은 별도 보상 조건으로 검사하며 기존 거점의 보상 검증을 약화하지 않았다.

검증 명령: `tools/verify_forest.ps1`. 남녀 모든 이동 프레임의 누락·잘림·정지 여부, 기존 커스터마이징과 저장, 방향별 공격 접촉, 개체 재생성, 단일 종 편성, 순찰 지점, 곡선 강변 양쪽 통행/입수 차단, 연못 차단과 기존 전체 경로를 검사한다.

실제 입력 캡처는 `DevCapture`로 게임에서 이동·달리기·공격을 실행했다. 캡처 시 체력을 회복해 사냥을 확인하며, 기존 저장 차단 규칙으로 사용자 세이브는 수정하지 않는다. 장시간 전투 밸런스와 일정한 프레임 속도는 이번 자동 검사만으로 보장하지 않는다.

최종 검증: 빌드 경고 0·오류 0, 임포트·3D reference-check·combat-check·selfcheck 모두 통과. 경로·강변 3,998표본, 연결 가능 59,650칸, 기존 고블린 윤곽 7,068표본 불일치 0. 로그: [전체 검증](movement-forest-verify.log).

최종 플레이에서 과수 나무의 상자가 야생 구역에 반복되는 것을 확인해 무작위 과수 배치를 제거했다. 슬라임 지대의 큰 흙바닥은 세 개의 작은 공터와 연결 길로 줄여 풀밭·연못·수목 군락이 구분되도록 했다.
