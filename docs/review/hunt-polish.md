# 기존 숲 30분 사냥 검증

## 변경 내용
- 이동·공격 텍스처를 시작/외형 확정 시 준비하고 원본 이미지 바이트를 재사용한다. 걷기↔전력질주 전환 시 보행 위상을 유지하며 이동 속도에 맞춰 재생한다.
- 추가 검사로 외형 조회의 방어적 복사본이 준비된 텍스처 캐시를 지우는 문제를 발견했다. 캐시 키의 외형 비교를 객체 주소에서 색상·체형 등 실제 값으로 수정했으며 복사본을 통한 남녀 8방향 재사용을 검사한다.
- 타격 정지 중 누른 공격/회피도 기존 입력 버퍼에 보관한다. 공격 후딜→회피→반격을 연결하고 새 게임·로드·부활에서 남던 회피 쿨다운/무적 시간을 공통 초기화한다.
- 먼 비활성 몬스터의 중복 위치·윤곽 갱신, 정지 NPC의 동일 위치 쓰기를 생략한다. 지형 높이는 동일 계산값을 캐시한다. 지형 분할 수·윤곽 정밀도·3D 표현은 낮추지 않았다.
- 슬라임 피해 6→4, 예고 0.30→0.42초. 고블린 및 베기 진화 기준 300은 유지했다. 실제 측정에서 목표 성장 시간에 들어 추가 수치 변경은 하지 않았다.

## 성능 측정
PNG 저장을 끄고 월드 준비까지의 초기 로딩을 따로 기록한다. 월드 준비 후 첫 15초는 준비 구간으로 제외한다. 장시간 입력 플레이 결과는 중앙값 **18.40ms**, p95 **39.12ms**, p99 **68.15ms**, 최대 **416.28ms**, 50ms 초과 2,059/79,301프레임(2.60%)이다. 안정적인 60fps 목표는 아직 달성하지 못했다.

`tools/benchmark_hunt.ps1`은 동일한 마을·슬라임 지대·고블린 마을의 고정 시점에서 각각 45초 실행한다. 이동/전투 경로 측정은 위 30분 기록으로 분리한다. 주변 적 AI는 실행되므로 환경 변동은 남는다. `pre-npc`는 다른 최적화가 이미 적용된 상태로, 마지막 NPC 중복 위치 쓰기 제거 및 외형 복사본 캐시 수정 전의 기준이다. 최초 `hunt-before.log`는 로딩 타이머가 섞였으므로 개선율의 근거로 사용하지 않는다. 30분 기록은 이 마지막 두 수정 전 실행 결과이며, 최종본은 전체 회귀 검사와 지역별 벤치마크로 확인한다.

각 칸은 수정 전 → 최종이며 프레임 지연 단위는 ms다. 준비 구간을 제외한 표본만 집계한다.
