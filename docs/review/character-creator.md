# 캐릭터 생성과 고블린 윤곽 회귀 검사

갱신일: 2026-09-10

## 사용

처음 실행하거나 외형을 아직 확정하지 않은 기존 저장을 불러오면 캐릭터 생성 화면이 열린다. 외형을 확정한 뒤에는 그대로 이어서 시작한다. 게임 중 **C**, 또는 **P → 외형 변경**으로 다시 편집할 수 있다. 생성 중 월드는 일시 정지되며, 취소하면 이전 외형을 유지한다. 적용은 외형만 바꾸며 레벨·직업·숙련·위치를 초기화하지 않는다. 저장 실패 시 이전 외형을 복원하고 화면에서 재시도를 안내한다.

| 선택 | 남성 | 여성 |
|---|---:|---:|
| 헤어스타일 | 60 | 60 |
| 눈 모양 | 60 | 60 |
| 체형 | 6 | 6 |
| 머리색 | 30 | 30 |
| 피부색 | 12 | 12 |

헤어는 12개 기본 스타일과 5개 앞머리 컷을 조합한 **60개 형태**이며, 눈은 10개 윤곽과 6개 폭을 조합한 **60개 형태**다. 각각을 전부 독립적으로 제작한 원화 60장이라는 뜻은 아니다. 남녀는 얼굴·몸통 비율, 속눈썹, 헤어 길이와 이름을 구분한다. 체형은 머리 위치·몸통 폭·다리 길이를 조정하고, 색상 변경과 별도로 형상이 달라진다.

`CharacterArt`의 파츠 렌더러가 생성 화면, 캐릭터 기록, 실제 2D/3D 플레이어에 같은 모습을 제공한다. 큰 머리와 짧은 팔다리의 픽셀 캐릭터로 구성했다. 회전 8방향, 걷기, 공격을 미리 볼 수 있다. 기본/강공격의 기존 접촉 프레임 4/5와 `CombatMotion.Progress`를 사용하며 전투 수치·몬스터 충돌·지도 크기는 변경하지 않았다. 모든 외형/애니메이션 조합을 수작업으로 검수한 것은 아니다.

## 충돌 오류의 원인과 재현

이 작업 시작 시점에 이미 직선 꼭짓점 정리 수정이 존재했고, 수정 전 현재 저장소의 `tools/verify_forest.ps1`도 통과했다. 이번에는 기존 수정의 효과를 재현·수치 검증하고 정상 구현의 정리 단계를 `SpriteCollision3D.CleanContour`로 분리했다.

```powershell
godot --headless --path . -- --reproduce-raw-contour
```

위 명령만 **수정 전 원본 윤곽**을 네이티브 분해기에 넘긴다. 고블린 북동쪽 `attack/frame_005`에서 `Convex decomposing failed!`가 재현된다. `Bitmap.OpaqueToPolygons(..., 1f)`의 단순화가 얇은 픽셀 돌기를 같은 직선 위로 되접으면서, 인접한 선분이 반대 방향으로 겹쳐 유효한 단순 다각형이 아니게 되는 것이 원인이다. 해당 원본에서 되접힘 2곳을 확인했다.

정상 경로는 면적이 없는 직선/되접힘 꼭짓점 4개를 제거한 후 46개 볼록 조각으로 분해한다. 기존 알파 기준 0.3, 1픽셀 윤곽 단순화, 오목한 형태, 깊이, 캐시를 유지했다. 전체를 하나의 볼록 껍질이나 사각형으로 대체하지 않았다.

- 재현 로그: `contour-repro.log`, `contour-repro-expected-errors.log` — 의도적으로 과거 오류를 발생시키는 별도 실행이다.
- 정상 회귀 검사: `SpriteContourChecks.Verify` — 정리 전후 부호 있는 면적 보존, 형상 캐시 재사용, 7,068개 픽셀 표본에서 윤곽과 볼록 조각 합집합의 차이 **0**.
- 기존 L자 윤곽의 명중/빗나감 및 3D reference-check를 그대로 실행한다.

## 검증

```powershell
./tools/verify_forest.ps1
```

빌드 → Godot 임포트 → reference-check → combat-check → selfcheck를 실행한다. 임포트와 검사 모두 종료 코드 외에 표준 출력/오류의 엔진 오류를 실패로 처리한다. 최종 정상 실행 로그는 `forest-*.log`이며 위 의도적 재현 로그와 분리된다.

최종 결과: 빌드 경고 0/오류 0, reference-check 및 combat-check PASS, 데이터 직업 8/스킬 28/NPC 16 정상. 연결 가능 40,093칸과 경로·보급품 3,018표본을 유지했다. 남녀 생성 화면 캡처도 종료 코드 0, 엔진 오류 없이 완료했다.

`CustomizationChecks`는 남녀별 실제 이미지 해시로 헤어 60개·눈 60개·체형 6개의 중복 여부를 검사한다. 팔레트 수, 잘못된 저장 값 정리, 이전 저장 호환, 생성 중 일시 정지, 적용/취소, 외형 직렬화 왕복, 실제 필드 스프라이트 적용도 검사한다. 테스트·캡처는 사용자 저장을 쓰지 않는다.

작업 전 백업: `%TEMP%/TGIWTB-before-customization-20260910.zip`. [이번 작업의 소스 패치](character-creator.patch)는 이 백업과 비교하며 이전의 다른 변경을 포함하지 않는다. 새 외부 의존성이나 PixelLab 생성 비용은 추가하지 않았다.
