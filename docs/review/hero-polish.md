# 새잎 검객 외형·모션 개선

2026-09-13. PixelLab에서 남녀 검객 원화와 8방향 전용 모션을 생성했다. 기존 파츠 그림보다 작은 머리, 긴 팔다리, 가죽 장비·망토의 세부 명암을 사용한다. 특정 개발자의 원본 캐릭터를 그대로 복제한 자산은 아니다.

- 남성: `9cd50f46-be01-49fb-9cac-897bc5504cd0`
- 여성: `68a5ca29-1089-4555-8a31-e83fc4cb4035`
- 자산: 남녀 각각 대기 8장, 보행·달리기 각 64장, 베기·강타 각 72장. 총 560 PNG. 출처와 다운로드 경로는 `tools/hero_downloads.json`.
- 실행 경로: `PlayerCharacter.SpriteClip` → `CombatMotion.Progress` → `PlayerSprite` → `CharacterArt` / `PixelHeroArt`. 2D와 3D가 같은 텍스처를 사용한다.

`PixelLab 검객`이 기본 외형이다. 체형 6종, 머리색 30종, 피부색 12종을 지원하며 저장·불러오기와 게임 내 C키 편집에 연결했다. 헤어스타일·눈 모양은 새 원화에서 고정이며, 기존 남녀별 60종 파츠 조합은 `기존 파츠 조합` 모드에 보존했다. 새 원화에 적용되지 않는 파츠를 선택하는 화면은 표시하지 않는다. 색상 마스크는 현재 검객의 머리색·의상에 맞춰져 있어 다른 의상 자산을 추가할 때 별도 파츠 마스크 검토가 필요하다.

달리기와 보행은 서로 다른 8프레임 모션이다. 공격은 준비 자세, 큰 팔 동작, 무게를 실은 전진, 후속 자세가 있는 9프레임을 사용한다. 초기에 생성된 공격에는 뒤를 보던 캐릭터가 카메라를 향해 돌아서는 문제가 있어, 방향을 명시한 `hero_slash_fixed` / `hero_heavy_fixed`로 교체했다. 공격의 실제 접촉 프레임은 완성 그림으로 검토한다. 몸의 예비 이동은 4→6px, 전진은 8→11px이며 선딜과 활성 구간의 오프셋을 연속으로 연결했다. 전투의 피해량·사거리·충돌 형상은 이 작업에서 바꾸지 않았다.

검토 도구 `tools/review_hero_art.gd`는 소스 프레임을 수정하지 않고 방향별 시트를 만든다. 행은 남·남동·동·북동·북·북서·서·남서, 열은 0번부터의 프레임이다. `CustomizationChecks`는 실제 게임 렌더러로 남녀별 모션 시트도 출력한다.

공격 접촉 프레임은 성별·방향별로 다르므로 `PixelHeroArt.ContactFrame`의 검토값을 사용한다. `CombatMotion.Progress`는 준비 구간이 해당 프레임에 도달하지 않게 하고, 판정이 열리는 순간 그 프레임을 표시한다. 예를 들어 남성 남동 베기는 8번, 남성 남쪽 베기는 5번 프레임이다. 모든 방향을 같은 번호로 처리하던 차이를 보완했다.

`tools/verify_forest.ps1` 최종 통과: 빌드 경고 0·오류 0, 임포트·3D reference-check·combat-check·selfcheck 오류 0. 고블린 윤곽은 46개 convex 조각, 7,068표본 불일치 0을 유지했다. 연결 가능 40,093칸, 경로·보급품 3,018표본 검사도 통과했다. 새 남녀 560프레임의 누락 검사, 6개 체형·30개 머리색·12개 피부색 구분, 공격 자세의 머리색 변경, 저장·취소·필드 반영 검사와 기존 60/60 파츠 검사를 포함한다.
