# 새잎 마을과 연속 숲

갱신일: 2026-09-09

기존 13개 직사각형 지역과 성벽 도시를 활성 월드에서 제거했다. 224×192 범위의 굽은 외곽 지형 안에 작은 마을, 연속 숲길, 개울, 세 도하 지점, 벌목터, 정찰대, 고블린 부락과 고목 공터를 배치했다. 마을은 12채이며 안전 구역 바깥에 7개 전투 거점이 있다. 지형은 하나로 이어지고, 숨겨진 성소만 별도 내부 공간으로 이동한다.

- **화면:** 카메라를 향한 픽셀 아트의 이전 입체감을 복원했다. 발 위치와 같은 회전 기준으로 건물·몬스터 윤곽 충돌도 맞췄다. 숲의 경사와 외곽 능선, 방향광 그림자, 풀 군집을 추가했다. 나무는 줄기가 이동을 막고 잎 아래는 지나갈 수 있다.
- **마을:** 여관, 빵집, 약방, 대장간, 훈련소, 마구간, 예배당과 주택이 굽은 길을 공유한다. 문 앞 접근로와 NPC 16명의 앵커·예비 좌표·대사를 새 지도에 맞췄다.
- **전투:** PixelLab의 같은 플레이어로 검 상태를 만들고 8방향 보행·일반 공격·강공격을 연결했다. 일반 공격은 9프레임 중 4번, 강공격은 5번에서 판정이 시작한다. 선후딜 이동 배율을 높여 움직이며 공격하는 흐름을 유지했다. 고블린도 8방향 보행과 활 공격을 사용한다.
- **발견 요소:** 숲의 조사 대상은 저장 가능한 변화를 만들며, 숨겨진 성소의 입장·귀환과 부락 소탕 후 샛길 개방이 동작한다. 숨은 조건은 게임 화면에 목록으로 표시하지 않는다. 성소는 여러 공간과 좁은 연결부, 철턱 전투 및 별도 조명을 가진다.
- **저장:** 월드 버전이 다른 저장은 성장 정보를 유지하고 새 마을로 위치만 옮긴다. 실제 저장을 교체하기 전 `.before-forest` 백업을 보존하고 임시 파일 작성 후 교체한다. 캡처·물리 검증은 사용자의 저장을 쓰지 않는다.

## 검증

`tools/verify_forest.ps1`은 빌드 → Godot 이미지 임포트 → 물리/지도 검증 → 전투 검증 → 데이터 검증 순서로 실행한다.

- 빌드: 경고 0 / 오류 0 (`forest-build.log`).
- `--reference-check`: PASS, 실패 0. 마을 길 255칸의 막힘 0, 길·보급품 1,716표본, 연결 가능 20,374칸. 8방향 이동, 윤곽 명중/빗나감, 지형 접지, 발사체 차단, 조사와 성소 왕복, 저장 보호 포함 (`forest-reference-check.log`).
- `--combat-check`: PASS, 실패 0 (`forest-combat-check.log`).
- `--selfcheck`: 직업 8 / 스킬 28 / NPC 16 정상 (`forest-selfcheck.log`).
- `python tools/check_sprite_consistency.py sword sword_walk sword_heavy`: 세 클립 모두 통과 (`forest-art-check.log`).
- 성소의 석재 바닥·조명·별도 미니맵과 마을의 원형 훈련 공터를 실제 화면으로 확인했다.
- 고블린 북동쪽 활 발사 프레임의 되접힌 직선 윤곽을 정리했다. 해당 이미지의 충돌 형상 유지 검사를 추가했고, 검증 스크립트는 엔진 오류도 실패로 처리한다.
- Intel UHD 620에서 PNG 저장을 끈 305프레임 전투 측정: 구간별 중앙값 19.7–21.1ms, 전체 최대 80.0ms. 앞서 관찰한 500ms 이상 지연은 이 실행에서 재현되지 않았다. 긴 플레이의 성능 보장은 아니다 (`forest-combat-perf.log`). 최종 검사와 성능 실행의 오류 로그는 비어 있다.

## 표본과 자산

시점·지형의 높낮이·그림자는 사용자가 선택한 [사지방 개발자의 최근 엔진 변경 화면](https://www.youtube.com/shorts/lSbkw_eFKAg)을 참고했다. 이동하며 공격하기, 회피·패링과 급습은 [제작자의 공개 포트폴리오](https://coloso.co.kr/products/dictionary-devinairforce)에 소개된 방향을 참고했다. 영상만으로 원작 내부 엔진 수치나 소스를 확인할 수는 없으므로 동일 구현이라고 주장하지 않는다.
숲과 목조 건축을 어우러지게 하는 구성은 [FFXIV 그리다니아 소개](https://na.finalfantasyxiv.com/a_realm_reborn/sp/world/cities/gridania/)도 참고했다.

PixelLab 맵 오브젝트: 고블린 움막 `6979e76a-c453-4c8b-a8ad-abe1a00ffb31`, 뿌리 입구 `bf845381-2edc-4304-bb31-0f5d9eaebf31`. 원본 PNG는 `art/objects32/goblin_hut.png`, `root_entrance.png`에 보존한다.

작업 전 소스·데이터 백업: `%TEMP%/TGIWTB-before-forest-rebuild-20260908.zip`. 기존의 다른 수정은 일괄 되돌리지 않았다.
[숲 개편 전 백업과 비교한 소스·데이터 패치](forest-rebuild.patch)는 39개 파일을 포함한다. PNG 자산과 도구 변경은 위 자산 목록 및 검증 스크립트를 참조한다.
장시간 사냥 밸런스, 모든 직업의 전용 무기 모션, 자유 회전 및 다층 건물 실내는 이번 검증으로 보장하지 않는다.
