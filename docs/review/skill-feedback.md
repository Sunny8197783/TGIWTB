- 일반 베기: 청백색 초승달 궤적. 무거운 베기: 더 두꺼운 금빛 궤적. 스킬 JSON의 색과 판정 각도·사거리를 사용하며 실제 판정이 열릴 때 생성한다.
- 명중: 대상 위치의 밝은 불꽃, 강공격의 추가 충격 고리. 기존 히트스톱·음향·피격 반응과 함께 재생한다. 함성·마법의 기존 링도 밝은 테두리와 확장 연출을 사용한다.
- 카메라: 공격 방향으로 튕긴 뒤 반대로 반동하고 감쇠한다. 일반 0.12초, 강공격 0.18초. 3D 카메라가 플레이어를 재조준하며 흔들림을 상쇄하던 구조를 화면 투영 오프셋으로 수정했다. 줌에 따른 화면상 진폭 차이를 보정한다. HUD는 흔들리지 않는다.
- 조절: F3 → 화면 연출 → **화면 흔들림 강도 (0=끔)**. 0~1 범위에서 조절한다.
