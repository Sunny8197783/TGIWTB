# 숲 확장과 RPG UI

갱신일: 2026-09-09

## 맵

320×256 범위로 넓히되 기존 마을과 성소, 저장 위치를 유지했다. 두 숲 지형이 하나로 겹쳐 이어지며 경계와 높이장이 같은 외곽 정의를 사용한다.
연결해서 걸을 수 있는 타일은 20,374칸에서 40,093칸으로 약 1.97배 늘었다. 전투·탐험 거점 14곳, 연결 경로 11개, 개울 도하 지점 4곳이다.

동쪽 망루길, 이끼 정원 유적, 사냥꾼의 숲집, 순례자의 쉼터, 잊힌 채석장, 달빛 고목길, 남쪽 옛길을 추가했다. 망루·움막·석상·숲집·예배당·우물·수레·장작·벤치·등불을 장소별로 배치하고 주변 나무를 정리했다. 마지막 2D 통행 검사에서 발견한 옛길과 창고의 겹침도 수정했다.

## UI와 조작

- 목재색 배경, 황동 테두리, 양피지색 글자를 HUD·대화·창·버튼에 공통 적용했다.
- 생명·마나·스태미나의 현재값/최대값, 스킬 이름·준비 상태·남은 대기시간, 미니맵과 현재 위치를 표시한다.
- **P / 캐릭터 버튼:** 직업·레벨·기본/보정 능력치·현재 자원·초상을 확인한다.
- **B / 스킬 버튼:** 배운 기술을 선택해 효과·단축키·마나 소모·대기시간·숙련도·숙련 피해 보정을 확인한다. 습득과 진화를 반영하며 미습득 히든 스킬이나 조건은 표시하지 않는다.
- **Esc / 닫기:** 창을 닫는다. 창 뒤의 이동·공격·조사를 차단하며 세계 시간은 계속 흐른다.
- **F / 계속 듣기:** NPC 대화를 넘긴다. 대화 마치기 또는 Esc로 중단할 수 있다.
- **Space:** 회피는 스태미나 24를 사용한다. 최대 100, 사용 후 0.5초 동안 회복을 기다리고 초당 20씩 회복한다. 기존 저장에 스태미나가 없으면 가득 찬 상태로 불러온다.

능력치 배분·자유로운 스킬 슬롯 교체는 기존 게임에 없는 기능이므로 이번 읽기 중심 기록창에는 넣지 않았다.
