# 전투·아트·초원 개선 결과

갱신일: 2026-09-07

## 적용 범위

1. **공격 모션과 판정**: `CombatMotion.Progress`가 선딜·활성·후딜을 기존 punch/heavy/shout의 접촉 프레임에 매핑한다. 히트스톱 중 시각 상태도 정지한다. 플레이어의 근접 범위는 스킬 JSON의 cone/circle을 사용하며 F2도 같은 도형을 표시한다. 대상 반지름과 벽 차단은 별도 계산한다.
2. **타격 음향과 피격**: 휘두르기·명중·강타·피격·방어·패링·처치의 합성 음향 7개와 위치 기반 재생을 추가했다. 기존 플레이어에 PixelLab 피격 클립 8방향·각 6프레임을 연결했다. 기존 넉백·히트스톱·화면 반응과 함께 사용한다.
3. **벽과 투사체**: 근접·반격·몬스터 공격의 벽 차단을 검사한다. 투사체는 Godot 형상 스윕으로 한 물리 프레임의 전체 이동과 반지름을 검사하며, 시작점 겹침·빠른 이동·관통 후 벽 정지를 처리한다. 발사점부터 검사하도록 발사체를 사수 위치에서 생성한다.
4. **아트**: 슬라임·고블린 궁수·철턱 3종과 NPC 상인·경비·훈련관·주민 계열 4종의 PixelLab 이미지를 연결했다. NPC 16명은 역할 이미지를 공유한다. 투명 여백을 제외한 높이와 발 위치를 통일했다. `docs/pixellab-assets.json`과 `tools/download_actor_art.ps1`에 재다운로드 정보를 보관한다.
5. **초원 밀도**: 과수원 길목 → 다리 앞 야영지 → 동쪽 감시터에 2/3/4마리 편성을 배치했다. 연결길·우회길·보급품·지역 밖 재생성을 추가했다. 보급품은 저장 플래그로 중복 보상을 막는다. 경로와 거점에 바위·소품이 생성되지 않도록 예약 영역을 적용하고, 구역 난수 시드는 실행 간 동일하게 유지한다.

## 검증

- `dotnet build --no-restore -v quiet`: 최종 변경 빌드 성공, 경고 0 / 오류 0.
- `godot --headless --path . -- --combat-check`: PASS, 실패 0. 실제 Godot 공간에서 얇은 벽, 첫 충돌 대상, 관통 후 벽, 시작 겹침, 반지름 스침, 벽 너머 근접, 실제 Arrow/SkillBolt, 접촉 프레임, 초원 연결·우회 경로를 검사한다.
- `godot --headless --path . -- --selfcheck`: 세션 중 통과, 직업 8 / 스킬 28 / NPC 16.
- `python tools/check_sprite_consistency.py hurt`: 피격 스프라이트 검사 통과.
- `git diff --check`: 공백 오류 없음. Git의 기존 LF/CRLF 변환 안내만 출력.
- 실제 화면 캡처: `combat/f0091.png`, `town/f0061.png`. 전투에서 명중·피격·처치를 확인했고 두 실행의 오류 로그는 비어 있다.
- 상세 충돌 결과: `combat-check.log`. 캡처 실행에서는 `SaveSystem.Save`가 저장을 건너뛰어 기존 진행을 덮어쓰지 않는다.

## 현재 한계

- 몬스터는 8방향 기본 이미지와 절차적 움직임·피격 변형을 사용한다. 별도 걷기·공격 프레임 세트는 아직 없다.
- NPC는 역할별 공용 이미지이며, 개별 외형과 직업별 플레이어 무기 애니메이션은 후속 아트 작업이다.
- 사냥터 배치 변경은 초원에 적용했다. 다른 지역은 기존 편성을 유지한다.
- 짧은 실행·회귀 검증을 완료했으며 30분 사냥의 재미와 음향의 주관적 품질은 장시간 플레이로 추가 평가해야 한다. 캡처에는 화면 저장 비용이 포함되어 성능 벤치마크로 쓰지 않는다.
