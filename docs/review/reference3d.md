# 최신 표본 화면 반영 및 맵 일관성 점검

갱신일: 2026-09-08

사용자가 선택한 기준은 사지방 개발자의 최근 변경 후 화면이다. 공식 영상 [엔진 바꿨어여](https://www.youtube.com/shorts/lSbkw_eFKAg)의 높낮이·원근·그림자·해안을 참고했다. [마나 흐름 입력](https://www.youtube.com/shorts/RYpNenmLUGk)의 드래그 입력도 기존 스킬에 연결했다. 영상만으로 원작 내부 엔진이나 정확한 물리 수치는 확인할 수 없다.

## 적용

- 기본 실행은 Godot 3D 지형과 픽셀 캐릭터를 함께 표시한다. 원근 카메라 FOV 36°, 약 41° 내려다보는 각도, 부드러운 추적과 휠 줌을 적용했다.
- 초원에 언덕·낮은 강변·모래 해안·물결과 방향광 그림자를 적용했다. 지형 메쉬와 높이 계산은 같은 삼각형 보간을 사용한다.
- 실제 CharacterBody3D가 경사·중력·벽을 처리하고, 해결된 좌표를 기존 전투 모델로 돌려준다. 근접 시야 및 투사체 구체 스윕은 3D 공간을 검사한다. 기존 스킬 데이터·숙련·세이브·피격 프레임·음향은 재사용한다.
- 기존 PixelLab 캐릭터와 몬스터/NPC 이미지를 사용하고, 반복 소품은 MultiMesh로 묶었다. 허수아비는 전용 기존 이미지로 표시한다.
- 좌클릭 공격, 우클릭 드래그 직선/원/Z 스킬, WASD 이동, Space 회피, 휠 줌. 기존 키 입력도 유지한다. 제스처 연결 데이터는 `data/controls/gestures.json`에 있다.

## 맵 일관성

- 해안과 모래를 미니맵에도 표시하고 강이 모래를 가로지르는 부분은 물 표시를 우선한다. 사냥길과 다리도 미니맵에 표시한다.
- 해안 생성 규칙을 초기 배치부터 적용해 물 위 소품은 그림과 충돌체를 함께 제외한다.
- 지면에 붙는 밭 그림은 원래 바닥 기준점에 배치하고 경사면을 따라간다. 다리 장식 그림의 위치와 실제 통행 바닥이 달랐던 문제는 통행 타일 자체를 목재 바닥으로 표시해 해결했다.
- 마을 길 1,196칸 중 소품 차단 0칸. 초원 연결·우회 경로, 구역 성문 중심, 보급품 주변의 219개 표본에서 기존 통행 판정과 3D 장애물 검사를 통과했다. 모든 타일·모든 방향의 완전 탐색을 의미하지 않는다.

## 검증 및 화면

- `dotnet build --no-restore -v quiet`: 최종 빌드 경고 0 / 오류 0.
- `godot --headless --path . -- --reference-check`: PASS, 실패 0. 219개 맵 표본, 지면 충돌/착지·경사 이동·부활·강변 투사체 차단·높이 차 근접 차단·미니맵·제스처·저장 보호 검사. 로그: `reference-check.log`.
- `--combat-check`, `--selfcheck`: 세션 중 통과. 관련 로그: `combat-check.log`, `selfcheck.log`.
- 실제 다리 통과: x3888→4162, y1552 유지. 로그: `reference3d-bridge.log`. 최종 다리 재질 화면: `reference3d-final/f0061.png`.
- 전투 명중·피격·처치·거점 정리: `reference3d-combat/f0241.png`. 해안: `reference3d-coast/f0091.png`(미니맵 수정 전 화면).
- 반복 소품 처리 후 전투 캡처 구간은 약 252~301 그리기 호출, 프레임 중앙값 약 17ms였다. 캡처 비용이 포함되므로 지속 60fps 성능 보장 수치로 사용하지 않는다.
- 캡처는 기존 저장을 덮어쓰지 않으며 `--reference-check`는 기존 저장을 읽지도 않는다. `--flat`은 이전 2D 화면 확인용이다.

## 남은 차이

좌표 하나당 지면 높이 하나인 구조라 다층 실내·점프는 포함하지 않는다. 몬스터 전용 걷기/공격 프레임과 직업별 플레이어 무기 모션은 아직 없고, NPC 16명은 역할별 4종 이미지를 공유한다. 일부 성벽·바위는 단순 도형이라 표본과 아트 수준이 동일하지 않다. 30분 전투 흐름과 넓은 구역 전체의 시각적 완성도는 추가 플레이 평가가 필요하다.
