# 방향·윤곽 충돌·초보 마을 수정

갱신일: 2026-09-08

## 고친 원인

1. `PlayerCharacter.UpdateNormal`이 이동 방향을 매 프레임 마우스 방향으로 덮어썼다. 이동은 키 방향을 유지하고, 좌클릭 공격 중에만 커서로 조준한다. 3D에서 좌클릭이 자동으로 시선 고정을 만들던 동작도 제거했다. Tab 시선 고정은 유지한다.
2. 숨은 `CharacterBody2D.MoveAndSlide`와 새 3D 충돌이 동시에 이동을 제한했다. 3D에서 2D 이동 충돌 마스크를 끄고 네이티브 3D 결과만 적용한다. 생성·부활의 `IsWalkable`도 준비된 3D 공간의 `CanStand`를 사용한다.
3. 건물/소품의 평면 밑동 사각형을 종류와 무관하게 높이 2.8m의 벽으로 복제했다. 그 복제를 제거하고 불투명 이미지 윤곽을 분해한 형상을 사용한다. 바위도 표시한 메쉬와 같은 볼록 형상으로 충돌한다.
4. 길 검사 로그가 소품 생성 전에 실행되어 잘못된 0을 출력했다. 실제 3D 공간 생성 후 검사하도록 옮겼다. 이전 기록의 1,196칸 결과는 현재 검증 근거로 사용하지 않는다.

## 외형과 판정

- `SpriteCollision3D`는 알파 0.3 이상 윤곽을 1px 오차로 단순화하고 볼록 형상으로 나눠 건물과 몬스터가 공유한다. 투명한 바깥 여백과 오목한 빈 부분은 큰 사각형으로 막지 않는다.
- 몬스터의 이동용 발밑 캡슐과 피격 Area3D를 분리했다. 방향별 스프라이트 변경에 맞춰 피격 형상도 바뀐다. 근접 부채꼴/원과 투사체 스윕이 실제 피격 Area를 검사한다.
- 이미지가 카메라 쪽으로 기울며 바닥 기준점에서 벗어나지 않도록 세로축을 고정했다. 크기·잘린 투명 여백·좌우 반전을 그림과 충돌체에 함께 적용한다.
- F2: 근처 구조물은 반투명 녹색, 몬스터 피격 영역은 반투명 붉은색으로 표시한다. 죽거나 비활성화된 피격 영역은 숨긴다. 전투용 범위/벽 차단과 저장 보호는 기존 시스템을 재사용했다.

- 연결된 바위 타일은 하나의 각진 바위 메쉬로 합쳐 겹친 타원처럼 보이던 문제를 없앴다. 같은 메쉬로 충돌체를 만들며 지역의 기존 바위 색을 적용한다.
